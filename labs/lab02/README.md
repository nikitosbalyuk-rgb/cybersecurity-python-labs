# Лабораторна робота №2
**Варіант 1**: Аналізатор журналів веб-сервера (Nginx/Apache Access Log)

## Встановлення залежностей
pip install -r requirements.txt

## Структура вхідних даних
labs/lab02/data/
└── access.log

## Приклади запуску (CLI)
1. Демонстрація ООП моделі (Завдання 1):
python -m labs.lab02.main demo

2. Аналізатор логів веб-сервера (Завдання 2):
python -m labs.lab02.main analyze --log-file labs/lab02/data/access.log --output labs/lab02/data/report.json

## Параметри команди analyze
* `--log-file` (обов'язковий): Шлях до вхідного файлу логів.
* `--output` (обов'язковий): Шлях для збереження звіту.
* `--min-status`: Мінімальний статус-код помилки (за замовчуванням `400`).
* `--top`: Кількість IP-адрес у рейтингу (за замовчуванням `5`).
* `--format`: Формат вихідного файлу `json` або `csv` (за замовчуванням `json`).

## Обробка помилок
* Якщо лог-файл не знайдено, програма виводить помилку через `logging.error` і не падає.
* Неправильний формат email при створенні користувача перехоплюється і викликає `ValueError`.
* Спроба дістати закритий пароль через `account["password"]` викликає `KeyError`.
